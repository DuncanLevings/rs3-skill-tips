# Skilling Coach

Skilling Coach shows one short, useful tip at the moment you can use it. For example, it might mention an ore box when you start mining, or a better training method when you reach a new level. You can pin a tip as a goal or dismiss it for good.

**Status:** early development. The plugin loads and opens an empty panel; tips aren't in yet.

See [docs/implementation-plan.md](docs/implementation-plan.md) for the full design.

## Requirements

- [PrettyUI](https://prettyui.j3.gg/) from the Plugin Hub.
- No permissions. Skilling Coach doesn't use the internet or read chat.
